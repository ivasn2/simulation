# Simulation

Консольная пошаговая симуляция 2D-мира, населённого травоядными и хищниками. Учебный проект по [Java Роадмапу Сергея Жукова](https://zhukovsd.github.io/java-backend-learning-course/projects/simulation/).

Мир представляет собой матрицу N×M, в каждой клетке может находиться не более одного объекта или существа. Состояние перерисовывается в консоли на одном месте каждый ход.

## Что в мире

| Символ | Сущность | Поведение |
|--------|----------|-----------|
| 🌿 | `Grass` | ресурс, которым питаются травоядные |
| 🪨 | `Rock` | статичный объект, просто занимает клетку |
| 🌳 | `Tree` | статичный объект, просто занимает клетку |
| 🦌 | `Herbivore` | ищет траву, идёт к ней и съедает |
| 🐺 | `Predator` | ищет травоядного, подходит и атакует |

## Правила

- Каждый ход существо теряет часть HP от голода. При HP ≤ 0 оно исчезает.
- За ход существо проходит не больше клеток, чем позволяет его скорость.
- Путь к цели ищется поиском в ширину (BFS): существа обходят препятствия и других существ.
- Травоядное, съев траву, восстанавливает HP до максимума.
- Хищник атакует травоядное: HP жертвы уменьшается на силу атаки. Если жертва погибла, хищник занимает её клетку и восстанавливает HP. Если жива, хищник остаётся рядом и атакует снова на следующем ходу.
- Размножение: два существа одного вида рядом, у обоих HP больше половины максимума. Детёныш появляется на свободной соседней клетке, а родители тратят половину максимального HP.
- Если травы на карте становится слишком мало, она появляется снова.

Размер поля и характеристики существ (HP, скорость, сила атаки, голод) настраиваются в `Main` и в конструкторах `Herbivore` и `Predator`.

## Запуск

Нужна JDK 21 или новее. Из корня проекта:

```
javac -encoding UTF-8 -sourcepath src -d out src/Main.java
java -Dstdout.encoding=UTF-8 -cp out Main
```

Запускать лучше в настоящем терминале (Windows Terminal, PowerShell, iTerm и т. п.), а не в окне Run среды разработки: карта перерисовывается на месте через ANSI-последовательности, а окно Run IntelliJ IDEA их не выполняет.

В Windows PowerShell 5.1 для корректного вывода эмодзи перед запуском выполните:

```
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

Команды вводятся в консоль, после каждой Enter:

| Команда | Действие |
|---------|----------|

| `s` | продолжить |

## Структура проекта

```
src/
├── Main.java                  точка входа, настройка симуляции
├── entity/                    Entity, Creature, Herbivore, Predator, Grass, Rock, Tree
├── map/                       WorldMap (карта), Coordinates (координаты)
└── simulation/
    ├── Simulation.java        карта, счётчик ходов, рендерер, списки действий
    ├── ConsoleRenderer.java   отрисовка карты в консоли
    ├── BreadthFirstSearch.java  поиск пути
    └── action/                Action и его реализации:
                               MoveAllCreaturesAction, SpawnEntitiesAction, ReproduceAction
```

## Дизайн

- `WorldMap` хранит сущности в `HashMap<Coordinates, Entity>`: пустые клетки не хранятся, наружу отдаётся только копия коллекции, доступ идёт через методы (`addEntity`, `removeEntity`, `moveEntity`, `isCellEmpty` и др.).
- `Action` — интерфейс действия над картой. `Simulation` исполняет `initActions` один раз перед стартом и `turnActions` каждый ход.
- Поведение существ задаётся целью (`getTargetClass`) и реакцией на неё (`interact`), общая логика хода и еды лежит в `Creature`.
- Поиск пути вынесен в отдельный класс и общий для обоих видов существ.
